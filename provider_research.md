# Provider endpoint findings

- Official Ollama API documentation states Local base URL: `http://localhost:11434/api`.
- The same documentation states Ollama Cloud base URL: `https://ollama.com/api`.
- Kilo official AI Gateway documentation states its OpenAI-compatible base URL: `https://api.kilo.ai/api/gateway`.
- Kiro official search result identifies Kiro as an AI development environment with authentication/API-key documentation, but no public OpenAI-compatible model-list endpoint was verified. Kiro should remain Custom/unsupported until a specific API endpoint is provided.
